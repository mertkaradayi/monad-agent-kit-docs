Quick Example ​

typescript
import { MonadAgentKit } from "@monad-agent-kit/core"
import { tokenPlugin } from "@monad-agent-kit/plugin-token"
import { defiPlugin } from "@monad-agent-kit/plugin-defi"

const agent = new MonadAgentKit({
  privateKey: process.env.PRIVATE_KEY,
  chainId: 10143, // Monad Testnet
})

agent.use(tokenPlugin)
agent.use(defiPlugin)

// Check balance
const balance = await agent.execute("getBalance", {})
console.log(`Balance: ${balance.data.balance} MON`)

// Swap on Kuru DEX
const swap = await agent.execute("swap", {
  tokenIn: "MON",
  tokenOut: "USDC",
  amountIn: "1.0",
})
console.log(`Swapped! TX: ${swap.data.txHash}`)

Why Monad Agent Kit? ​

Generic EVM agent kits give you token transfers and contract calls. They miss the protocols that make Monad's ecosystem distinct: Kuru's on-chain order book, aPriori's liquid staking, Mon Name Service for human-readable addresses.

Monad Agent Kit provides first-class integrations with these native protocols while retaining full EVM compatibility. Your agent can resolve alice.mon to an address, swap on Kuru with limit orders, stake MON for aprMON, and call any arbitrary contract — all through a single, type-safe interface.

Install ​

bash
bun add @monad-agent-kit/core

Or with plugins:

bash
bun add @monad-agent-kit/core @monad-agent-kit/plugin-token @monad-agent-kit/plugin-defi

Or scaffold a complete project:

bash
bun create monad-agent
