Features

Everything your agent needs

From token transfers to DeFi strategies, every action is type-safe, tested, and ready to use.

Modular by design

Load only what you need. Token transfers, DeFi, NFTs, and staking ship as separate plugins.

50+ on-chain actions

Swap, stake, transfer, approve, query balances, get prices, manage liquidity, and more.

Fully type-safe

Every action, parameter, and return type is defined in TypeScript. No guessing, no runtime surprises.

Built-in safety rails

Spending limits, address whitelists, action scoping, and human approval gates protect every transaction.

Testnet and mainnet

Switch between Monad testnet and mainnet with a single config change. Same code, same API.

Flexible wallet support

Private keys, pre-configured accounts, or any EIP-1193 provider. Works with MetaMask, WalletConnect, and more.

Developer Experience

Ship in minutes, not days

typescript
import { MonadAgentKit } from "@monad-agent-kit/core"
import { defiPlugin } from "@monad-agent-kit/plugin-defi"

const agent = new MonadAgentKit({ chainId: 143 })
await agent.use(defiPlugin)

const price = await agent.execute("getTokenPrice", {
  token: MON,
  quoteToken: USDC,
})

console.log(price.data.price) // "$8.42"
