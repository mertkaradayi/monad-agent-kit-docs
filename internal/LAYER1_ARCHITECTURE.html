Layer 1: Monad Agent Kit - Architecture Plan ​

Overview ​

Build an open-source TypeScript SDK that enables any AI agent to perform onchain actions on Monad blockchain.

Goal: Create the foundational infrastructure that becomes the standard for AI-Monad interactions.

Tech Stack ​

ComponentChoiceRationale
LanguageTypeScriptType safety, industry standard, matches Solana Agent Kit
EVM LibraryviemModern, fast, excellent TypeScript support
Runtime/Package ManagerBunAll-in-one: runtime, package manager, bundler, test runner
Buildbun buildBuilt-in, no extra config needed
Testingbun:testBuilt-in test runner, fast
LintingBiomeFast, unified linter + formatter
DocsVitePressLightweight, Vue-based, great for libraries
CI/CDGitHub ActionsStandard, free for open source

Core Package Design ​

MonadAgentKit Class ​

typescript
// packages/core/src/agent.ts

export interface AgentConfig {
  rpcUrl?: string
  account: Account | PrivateKeyAccount
  chainId?: number
}

export class MonadAgentKit {
  public readonly wallet: WalletClient
  public readonly publicClient: PublicClient
  private plugins: Map<string, Plugin> = new Map()
  private actions: Map<string, Action> = new Map()

  constructor(config: AgentConfig)

  // Plugin management
  use(plugin: Plugin): this

  // Action registry
  registerAction(action: Action): void
  getAction(name: string): Action | undefined
  getAllActions(): Action[]

  // Execute actions
  execute<T>(actionName: string, params: unknown): Promise<ActionResult<T>>

  // Get tools for AI frameworks
  getTools(): ToolDefinition[]

  // Utility methods
  getAddress(): Address
  getBalance(token?: Address): Promise<bigint>
}

Plugin Interface ​

typescript
// packages/core/src/plugin.ts

export interface Plugin {
  name: string
  description: string
  version: string
  actions: Action[]

  // Called when plugin is registered
  initialize?(agent: MonadAgentKit): Promise<void>
}

export function definePlugin(config: PluginConfig): Plugin

Action Interface ​

typescript
// packages/core/src/action.ts

export interface Action<TParams = unknown, TResult = unknown> {
  name: string
  description: string
  category: string
  parameters: JSONSchema7          // For AI tool generation

  execute(
    params: TParams,
    context: ActionContext
  ): Promise<ActionResult<TResult>>

  // Optional: validate params before execution
  validate?(params: TParams): ValidationResult

  // Optional: simulate before execution
  simulate?(params: TParams, context: ActionContext): Promise<SimulationResult>
}

export interface ActionContext {
  wallet: WalletClient
  publicClient: PublicClient
  agent: MonadAgentKit
}

export interface ActionResult<T = unknown> {
  success: boolean
  data?: T
  transactionHash?: Hash
  error?: {
    code: string
    message: string
  }
}

export function defineAction<TParams, TResult>(
  config: ActionConfig<TParams, TResult>
): Action<TParams, TResult>

AI Framework Integrations ​

LangChain ​

typescript
// packages/ai-langchain/src/tools.ts

import { DynamicStructuredTool } from '@langchain/core/tools'

export function createLangChainTools(agent: MonadAgentKit): DynamicStructuredTool[] {
  return agent.getAllActions().map(action =>
    new DynamicStructuredTool({
      name: action.name,
      description: action.description,
      schema: jsonSchemaToZod(action.parameters),
      func: async (params) => {
        const result = await agent.execute(action.name, params)
        return JSON.stringify(result)
      }
    })
  )
}

Vercel AI SDK ​

typescript
// packages/ai-vercel/src/tools.ts

import { tool } from 'ai'

export function createVercelAITools(agent: MonadAgentKit): Record<string, CoreTool> {
  const tools: Record<string, CoreTool> = {}

  for (const action of agent.getAllActions()) {
    tools[action.name] = tool({
      description: action.description,
      parameters: jsonSchemaToZod(action.parameters),
      execute: async (params) => agent.execute(action.name, params)
    })
  }

  return tools
}

Testing Strategy ​

Unit Tests ​

  • Core: Plugin registration, action registry, wallet abstraction
  • Plugins: Action parameter validation, error handling

Integration Tests (Testnet) ​

  • Token transfers on Monad testnet
  • Swaps on Kuru testnet
  • Staking on aPriori testnet

E2E Tests ​

  • Full flow: Initialize agent → register plugins → execute action → verify result
  • AI integration: LangChain agent executing real actions

Verification Checklist ​

After implementation, verify:

  1. Core Package

    bash
    bun test --filter @monad-agent-kit/core

  2. Token Plugin

    bash
    # Run example
bun run --cwd examples/basic-transfer start

  3. DeFi Plugin

    bash
    # Run swap example
bun run --cwd examples/swap-tokens start

  4. AI Integration

    bash
    # Run LangChain example
bun run --cwd examples/langchain-agent start

  5. Build All

    bash
    bun run build
bun run lint
bun test

Decisions Made ​

  • Package scope: @monad-agent-kit/* (e.g., @monad-agent-kit/core)
  • License: MIT
  • Runtime/Package Manager: Bun (all-in-one: runtime, package manager, bundler, test runner)
