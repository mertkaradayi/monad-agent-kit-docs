What Each Kit Does Well ​

Solana Agent Kit — Deep protocol coverage

  • NFT minting, listing, metadata via Metaplex
  • Compressed airdrops (ZK proofs via Light Protocol)
  • Perpetual trading (Drift, Adrena)
  • Limit orders (Manifest)
  • Cross-chain bridging (Wormhole, deBridge)
  • Token launches (Pump.fun)
  • Domain registration (SNS, Alldomains)
  • Price feeds (Pyth, CoinGecko)

Coinbase AgentKit — Safety and wallet infrastructure

  • Multiple wallet providers (CDP Smart Wallet, Privy, Viem)
  • Smart wallet support (account abstraction)
  • Fiat onramp built-in
  • Action provider scoping, least-privilege security model
  • Human approval gates for high-risk operations
  • Quickstart CLI (npm create onchain-agent@latest)
  • Both TypeScript and Python SDKs

GOAT SDK — Breadth and framework coverage

  • 200+ plugins across every major protocol
  • 15+ chains, 12+ wallet providers
  • 10+ AI framework adapters (including Eliza, CrewAI, GAME)
  • Prediction markets (Polymarket)
  • Modular "install only what you need" architecture

Our Unique Strengths ​

  • Portfolio tracking with USD values — No other kit has this built-in
  • Batch transfers (mixed native + ERC-20) — Unique feature
  • Multi-swap (split, consolidate, batch) — Unique feature
  • Token price via on-chain DEX quotes — More decentralized than CoinGecko API dependency
  • Monad-first — Deep integration with Monad protocols (Kuru, aPriori) that no other kit covers

Feature Roadmap ​

Core & Tokens ​

  • [x] Token transfers, balances, approve, allowance — plugin-token
  • [x] Token info & pricing — getTokenInfo, getTokenPrice in plugin-tokens
  • [x] Transaction history — getTransactionHistory in plugin-tokens
  • [x] Token discovery / portfolio — getPortfolio via Multicall3 in plugin-tokens
  • [x] First activity detection — getFirstActivity in plugin-tokens
  • [x] NFT support — getNFTs, transferNFT, getNFTMetadata (ERC-721) in plugin-nft

DeFi ​

  • [x] DEX swaps — Kuru DEX (getQuote, swap)
  • [x] DEX aggregation — 0x (getQuote0x, swap0x, getBestQuote)
  • [x] Staking — aPriori (stake, requestUnstake, claimUnstake, getStakeInfo)
  • [x] Liquidity provision — Kuru (addLiquidity, removeLiquidity, getPoolInfo)
  • [x] Wrap/Unwrap — wrapMON, unwrapWMON
  • [x] LP position tracker — Query user's LP positions on Kuru pools (getLPPositions)
  • [x] Limit orders — Place, cancel, and query limit orders on Kuru (placeLimitOrder, cancelLimitOrder, getLimitOrders)
  • [ ] Lending protocols — Deposit, borrow, repay (when Monad lending protocols launch)
  • [ ] Yield farming — Auto-compound, farm positions

Gas & Transactions ​

  • [x] Batch transactions — batchTransfer in plugin-token, multiSwap in plugin-defi
  • [x] Gas estimation — estimateGas action in plugin-tokens: gas units, gas price, cost in MON
  • [x] Tx simulation — eth_call to dry-run, show balance changes & potential errors

Safety & Infrastructure ​

  • [x] Safety rails — SafetyPolicy in core: action scoping, spending limits (per-action & daily), human approval gates
  • [x] Address whitelist — Only interact with approved addresses, integrated in SafetyPolicy
  • [x] Multiple wallet providers — EIP-1193 adapter for any browser/injected provider
  • [ ] Multi-sig support — Safe/multi-sig wallet integration

Agent Intelligence ​

  • [ ] Price alerts — Notify when token hits target price
  • [ ] Auto-rebalance — Keep portfolio at target allocations
  • [ ] DCA bot — Dollar-cost averaging into tokens
  • [ ] Copy trading — Mirror another wallet's trades

Analytics ​

  • [ ] PnL tracking — Calculate profit/loss on positions
  • [ ] Portfolio analytics — Charts, allocation breakdown
  • [ ] Whale watching — Track large wallets

Developer Experience ​

  • [x] Quickstart CLI — npm create monad-agent scaffolding
  • [x] Generic contract interaction — User-facing readContract/writeContract actions
  • [x] ENS / name resolution — Extensible resolver interface (NameResolver, resolveNameOrAddress)

Long-term ​

  • [ ] Cross-chain bridging — When bridges are live on Monad
  • [ ] Python SDK — Coinbase and GOAT both have it
  • [ ] Action composability — Workflows chaining multiple actions
  • [x] Agent memory / tx log — Persistent action history
  • [x] Event monitoring — Subscribe to on-chain events (subscribeEvents, getEventLog, unsubscribeEvents)
