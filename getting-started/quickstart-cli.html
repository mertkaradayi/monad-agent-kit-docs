Quickstart CLI ​

Scaffold a ready-to-run MCP server project for Claude Desktop in one command.

Usage ​

bash
bun create monad-agent my-agent

This creates a my-agent/ directory with a working MCP server pre-configured with all Monad Agent Kit plugins.

my-agent/
├── index.ts           # MCP server entry point
├── package.json       # Dependencies
├── tsconfig.json      # TypeScript config
├── .env.example       # Environment template
├── .gitignore         # Ignore .env, node_modules
└── README.md          # Setup + usage guide

Setup ​

bash
cd my-agent
bun install
cp .env.example .env   # Add your PRIVATE_KEY

Add to Claude Desktop config (~/Library/Application Support/Claude/claude_desktop_config.json):

json
{
  "mcpServers": {
    "my-agent": {
      "command": "bun",
      "args": ["start"],
      "cwd": "/absolute/path/to/my-agent",
      "env": {
        "PRIVATE_KEY": "0x..."
      }
    }
  }
}

Restart Claude Desktop and ask: "What's my MON balance?"

Included Tools ​

The generated server includes these MCP tools out of the box:

ToolDescription
getMyWalletWallet address and MON balance
getTokenBalanceERC-20 token balance
transferSend MON or ERC-20 tokens
swapSwap tokens on Kuru DEX
getSwapQuoteGet swap quote without executing
getPortfolioFull portfolio with USD values
getTokenInfoToken metadata
getTokenPriceReal-time price via DEX quote
stakeMONStake MON for aprMON
getStakeInfoStaking position and rewards

Customization ​

The generated index.ts is a standalone file you own. Add more tools, modify existing ones, or integrate additional plugins as needed. See the Actions reference for all available actions.

npm Compatibility ​

The CLI also works with npm/npx:

bash
npx create-monad-agent my-agent
