Providing Liquidity ​

This guide walks you through adding concentrated liquidity to a Kuru DEX pool.

Prerequisites ​

  • Completed Your First Swap guide
  • MON and USDC in your wallet

Understanding Concentrated Liquidity ​

Kuru DEX uses concentrated liquidity, where you specify a price range for your position:

  • Price Range: Your liquidity only earns fees when the price is within your range
  • Narrower Range: Higher capital efficiency, more fees, but more risk of being out of range
  • Wider Range: Lower risk, but less capital efficient

Step 1: Set Up ​

typescript
import { MonadAgentKit } from "@monad-agent-kit/core"
import { tokenPlugin } from "@monad-agent-kit/plugin-token"
import { defiPlugin } from "@monad-agent-kit/plugin-defi"

const agent = new MonadAgentKit({
  privateKey: process.env.PRIVATE_KEY as `0x${string}`,
  chainId: 10143,
})

await agent.use(tokenPlugin)
await agent.use(defiPlugin)

Step 2: Get Pool Information ​

typescript
const POOL_ADDRESS = "0x..." // MON/USDC pool

const poolInfo = await agent.execute("getPoolInfo", {
  pool: POOL_ADDRESS,
})

if (poolInfo.success) {
  console.log("Pool Info:")
  console.log(`  Base Asset: ${poolInfo.data.baseAsset}`)
  console.log(`  Quote Asset: ${poolInfo.data.quoteAsset}`)
  console.log(`  Tick Size: ${poolInfo.data.tickSize}`)
  console.log(`  Min Size: ${poolInfo.data.minSize}`)
}

Step 3: Wrap MON (if needed) ​

Many pools use WMON instead of native MON:

typescript
// Wrap 10 MON to WMON
const wrap = await agent.execute("wrapMON", {
  amount: "10.0",
})

if (wrap.success) {
  console.log(`Wrapped 10 MON to WMON`)
}

Step 4: Add Liquidity ​

typescript
// Add liquidity with 100 USDC, price range $0.90 - $1.10
const lp = await agent.execute("addLiquidity", {
  pool: POOL_ADDRESS,
  quoteLiquidity: "100",  // 100 USDC
  startPrice: "0.9",      // Lower bound
  endPrice: "1.1",        // Upper bound
  strategy: "spot",       // Even distribution
})

if (lp.success) {
  console.log("Liquidity added!")
  console.log(`  Quote deposited: ${lp.data.quoteLiquidity}`)
  console.log(`  Base deposited: ${lp.data.baseLiquidity}`)
  console.log(`  Bid orders: ${lp.data.numBids}`)
  console.log(`  Ask orders: ${lp.data.numAsks}`)
  console.log(`  TX: ${lp.data.txHash}`)
}

Distribution Strategies ​

StrategyDistributionBest For
spotEven across rangeGeneral use
curveMore at center (U-shape)Stable pairs
bidaskMore at edges (triangular)Volatile pairs
typescript
// Use curve strategy for stable pairs
const lp = await agent.execute("addLiquidity", {
  pool: POOL_ADDRESS,
  quoteLiquidity: "100",
  startPrice: "0.99",
  endPrice: "1.01",
  strategy: "curve",
})

Step 5: Monitor Your Position ​

Check the Monad Explorer for your position:

https://testnet.monadexplorer.com/tx/{txHash}

Note the order IDs from the transaction - you'll need them to remove liquidity.

Step 6: Remove Liquidity ​

typescript
// Remove liquidity using order IDs from Step 5
const remove = await agent.execute("removeLiquidity", {
  pool: POOL_ADDRESS,
  orderIds: [1, 2, 3, 4, 5], // Your order IDs
})

if (remove.success) {
  console.log(`Removed ${remove.data.ordersAttempted} orders`)
  console.log(`TX: ${remove.data.txHash}`)
}

Tips ​

  1. Start Small: Test with small amounts first
  2. Monitor Price: Your liquidity is only active within your range
  3. Rebalance: Consider adjusting your range if price moves significantly
  4. Fees: You earn fees proportional to your share of in-range liquidity

Understanding Pool Constraints ​

Before adding liquidity, always check pool parameters:

typescript
const poolInfo = await agent.execute("getPoolInfo", { pool: POOL_ADDRESS })
console.log("Pool minSize:", poolInfo.data.minSize)
console.log("Pool tickSize:", poolInfo.data.tickSize)

Key constraints:

  • minSize: Minimum size for each position. Larger values require more capital.
  • tickSize: Determines price granularity. Affects how many positions are created in a range.

If your liquidity is spread too thin across many positions, each individual position may fall below the pool's minSize, causing MIN_SIZE_ERROR.

Solutions:

  1. Use a tighter price range (fewer positions)
  2. Increase liquidity amount
  3. Try a different pool with lower minSize requirements

See Known Limitations for more details.
