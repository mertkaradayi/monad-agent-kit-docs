Wallet Providers ​

MonadAgentKit supports three ways to provide a wallet:

  1. Private key — Server-side agents, scripts, bots
  2. Account — Pre-configured viem account (custom signers)
  3. EIP-1193 provider — Browser wallets, WalletConnect, Privy, Coinbase Wallet

Private Key (default) ​

The simplest option for server-side agents:

typescript
const agent = new MonadAgentKit({
  privateKey: "0x...",
  chainId: 10143,
})

Pre-configured Account ​

Use any viem-compatible Account object:

typescript
import { privateKeyToAccount } from "viem/accounts"

const account = privateKeyToAccount("0x...")

const agent = new MonadAgentKit({
  account,
  chainId: 10143,
})

EIP-1193 Provider ​

Use any EIP-1193 compatible provider — MetaMask, WalletConnect, Coinbase Wallet, Privy, or any injected browser wallet.

Since the provider needs an async eth_requestAccounts call, use the static create() method:

typescript
import { MonadAgentKit } from "@monad-agent-kit/core"

// Browser wallet (e.g., MetaMask)
const agent = await MonadAgentKit.create({
  provider: window.ethereum,
  chainId: 10143,
})

// WalletConnect
import { EthereumProvider } from "@walletconnect/ethereum-provider"

const wcProvider = await EthereumProvider.init({
  projectId: "YOUR_PROJECT_ID",
  chains: [10143],
})
await wcProvider.connect()

const agent = await MonadAgentKit.create({
  provider: wcProvider,
  chainId: 10143,
})

How it works ​

  • The provider is used as both the transport (for RPC calls) and the signer (for transactions)
  • eth_requestAccounts is called to get the connected account
  • A json-rpc account is created — all signing is delegated to the provider
  • Plugins work identically regardless of wallet type

Low-level API ​

You can also use createWalletFromProvider() directly:

typescript
import { createWalletFromProvider } from "@monad-agent-kit/core"

const { wallet, publicClient, account } = await createWalletFromProvider({
  provider: window.ethereum,
  chainId: 10143,
})

Validation ​

Only one wallet source can be provided. Passing multiple sources throws an error:

typescript
// Throws: "Provide only one of privateKey, account, or provider"
new MonadAgentKit({
  privateKey: "0x...",
  provider: window.ethereum,
})
