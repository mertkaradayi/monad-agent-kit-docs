Creating Custom Plugins ​

This guide shows you how to build your own plugin with custom actions.

Plugin Structure ​

A plugin is an object with:

  • name: Unique plugin identifier
  • description: What the plugin does
  • version: Semantic version
  • actions: Array of action definitions

Step 1: Create Action ​

typescript
// my-plugin/actions/greet.ts
import { defineAction, successResult } from "@monad-agent-kit/core"

interface GreetParams {
  name: string
}

interface GreetResult {
  message: string
  timestamp: string
}

export const greetAction = defineAction<GreetParams, GreetResult>({
  name: "greet",
  description: "Greet someone with a friendly message",
  category: "custom",

  parameters: {
    type: "object",
    properties: {
      name: {
        type: "string",
        description: "Name of the person to greet",
      },
    },
    required: ["name"],
  },

  validate(params) {
    const errors = []

    if (!params.name || params.name.trim() === "") {
      errors.push({ field: "name", message: "Name is required" })
    }

    return {
      valid: errors.length === 0,
      errors: errors.length > 0 ? errors : undefined,
    }
  },

  async execute(params) {
    return successResult<GreetResult>({
      message: `Hello, ${params.name}! Welcome to Monad.`,
      timestamp: new Date().toISOString(),
    })
  },
})

Step 2: Create Plugin ​

typescript
// my-plugin/index.ts
import { definePlugin } from "@monad-agent-kit/core"
import { greetAction } from "./actions/greet"

export const myPlugin = definePlugin({
  name: "my-plugin",
  description: "My custom plugin for Monad Agent Kit",
  version: "1.0.0",
  actions: [greetAction],
})

Step 3: Use Plugin ​

typescript
import { MonadAgentKit } from "@monad-agent-kit/core"
import { myPlugin } from "./my-plugin"

const agent = new MonadAgentKit({
  privateKey: process.env.PRIVATE_KEY as `0x${string}`,
})

await agent.use(myPlugin)

const result = await agent.execute("greet", { name: "Alice" })
console.log(result.data.message)
// "Hello, Alice! Welcome to Monad."

Using Context ​

Actions receive a context object with blockchain clients:

typescript
async execute(params, context) {
  // Read from blockchain
  const balance = await context.publicClient.getBalance({
    address: context.agent.getAddress(),
  })

  // Write to blockchain
  const hash = await context.wallet.sendTransaction({
    to: params.to,
    value: parseEther(params.amount),
  })

  // Agent info
  const chainId = context.agent.getChainId()
  const isTestnet = context.agent.isTestnet()

  return successResult({ balance, hash, chainId })
}

Error Handling ​

typescript
import { errorResult, successResult } from "@monad-agent-kit/core"

async execute(params, context) {
  try {
    // Do something
    const result = await doSomething()

    return successResult({ data: result })
  } catch (error) {
    return errorResult(
      "MY_ERROR_CODE",
      error.message || "Something went wrong"
    )
  }
}

Transaction Actions ​

For actions that send transactions:

typescript
async execute(params, context) {
  const tx = await context.wallet.sendTransaction({
    to: params.to,
    value: parseEther(params.amount),
  })

  const receipt = await context.publicClient.waitForTransactionReceipt({
    hash: tx,
  })

  return successResult(
    {
      txHash: receipt.transactionHash,
      to: params.to,
      amount: params.amount,
    },
    receipt.transactionHash // Pass txHash for explorer URL
  )
}

Full Example: NFT Plugin ​

typescript
// nft-plugin/actions/mint.ts
import { defineAction, errorResult, successResult } from "@monad-agent-kit/core"
import { parseAbi } from "viem"

const NFT_ABI = parseAbi([
  "function mint(address to) public returns (uint256)",
])

export const mintNFTAction = defineAction({
  name: "mintNFT",
  description: "Mint an NFT to an address",
  category: "nft",

  parameters: {
    type: "object",
    properties: {
      contract: { type: "string", description: "NFT contract address" },
      to: { type: "string", description: "Recipient address" },
    },
    required: ["contract", "to"],
  },

  async execute(params, context) {
    try {
      const hash = await context.wallet.writeContract({
        address: params.contract,
        abi: NFT_ABI,
        functionName: "mint",
        args: [params.to],
      })

      const receipt = await context.publicClient.waitForTransactionReceipt({
        hash,
      })

      return successResult(
        { txHash: hash, contract: params.contract, to: params.to },
        hash
      )
    } catch (error) {
      return errorResult("MINT_FAILED", error.message)
    }
  },
})

Using Shared Utilities ​

The core package provides utilities for common operations:

typescript
import {
  getTokenDecimals,
  isNativeToken,
  normalizeAddress,
  getExplorerTxUrl,
  MAINNET_CHAIN_ID,
  TESTNET_CHAIN_ID,
} from "@monad-agent-kit/core"

async execute(params, context) {
  // Validate address input
  const tokenAddress = normalizeAddress(params.token)
  if (!tokenAddress) {
    return errorResult("INVALID_ADDRESS", "Invalid token address")
  }

  // Check if native token
  if (isNativeToken(tokenAddress)) {
    // Handle native MON differently
  }

  // Get token decimals
  const decimals = await getTokenDecimals(context.publicClient, tokenAddress)

  // After transaction, return explorer URL
  const txUrl = getExplorerTxUrl(context.agent.getChainId(), txHash)

  return successResult({ txHash, explorerUrl: txUrl })
}

Best Practices ​

  1. Validate Early: Check parameters before making blockchain calls
  2. Handle Errors: Always catch and return meaningful error codes
  3. Type Everything: Use TypeScript for parameters and results
  4. Document Actions: Clear descriptions help AI understand usage
  5. Test Thoroughly: Write tests for validation and execution
  6. Use Shared Utilities: Prefer normalizeAddress(), getTokenDecimals(), etc. over duplicating logic
