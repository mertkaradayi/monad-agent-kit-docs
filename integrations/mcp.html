Claude Desktop (MCP) Integration ​

Use Monad Agent Kit directly in Claude Desktop via Model Context Protocol.

Overview ​

The MCP server exposes all agent actions as tools that Claude can use directly. This enables natural language blockchain interactions without writing code.

Setup ​

1. Install the MCP Server ​

bash
mkdir monad-mcp && cd monad-mcp
bun init -y
bun add @monad-agent-kit/core @monad-agent-kit/plugin-token @monad-agent-kit/plugin-defi

See the @monad-agent-kit/core package on npm for full details.

2. Configure Environment ​

Create .env:

bash
PRIVATE_KEY=0x...your-private-key...
CHAIN_ID=10143  # Monad Testnet

3. Configure Claude Desktop ​

Edit ~/Library/Application Support/Claude/claude_desktop_config.json:

json
{
  "mcpServers": {
    "monad-agent-kit": {
      "command": "bun",
      "args": ["run", "/path/to/mcp-claude-desktop/index.ts"],
      "env": {
        "PRIVATE_KEY": "0x...",
        "CHAIN_ID": "10143"
      }
    }
  }
}

4. Restart Claude Desktop ​

Restart the app to load the MCP server.

Example Conversations ​

Check Balance ​

You: What's my MON balance?

Claude: Let me check your wallet balance.

Uses getMyWallet tool

Your wallet 0x742d... has 15.25 MON on Monad Testnet.

Execute Swap ​

You: Swap 5 MON for USDC

Claude: I'll get a quote first to see what you'll receive.

Uses getSwapQuote tool

You'll receive approximately 7.5 USDC for 5 MON (0.1% price impact).

Uses swapTokens tool

Done! Swapped 5 MON for 7.48 USDC. View transaction

Stake MON ​

You: Stake 10 MON

Claude: I'll stake 10 MON via aPriori for you.

Uses stakeMON tool

Staked 10 MON and received 9.85 aprMON. View transaction

Your aprMON will appreciate over time. To unstake later, just ask!

Provide Liquidity ​

You: Add 100 USDC of liquidity to the MON/USDC pool between $0.90 and $1.10

Claude: I'll add concentrated liquidity to that range.

Uses addLiquidity tool

Added liquidity successfully:

  • Quote: 100 USDC
  • Base: 66.67 WMON
  • Created 10 bid orders and 10 ask orders
