Vercel AI SDK Integration ​

Build AI-powered blockchain applications with the Vercel AI SDK.

Installation ​

bash
bun add @monad-agent-kit/ai-vercel ai @openrouter/ai-sdk-provider

Basic Usage ​

typescript
import { MonadAgentKit } from "@monad-agent-kit/core"
import { tokenPlugin } from "@monad-agent-kit/plugin-token"
import { defiPlugin } from "@monad-agent-kit/plugin-defi"
import { createVercelAITools } from "@monad-agent-kit/ai-vercel"
import { generateText } from "ai"
import { createOpenRouter } from "@openrouter/ai-sdk-provider"

// 1. Create agent
const agent = new MonadAgentKit({
  privateKey: process.env.PRIVATE_KEY as `0x${string}`,
})
await agent.use(tokenPlugin)
await agent.use(defiPlugin)

// 2. Create tools
const tools = createVercelAITools(agent)

// 3. Use with AI model
const openrouter = createOpenRouter({
  apiKey: process.env.OPENROUTER_API_KEY,
})

const result = await generateText({
  model: openrouter("anthropic/claude-sonnet-4"),
  tools,
  maxSteps: 5,
  prompt: "Check my MON balance and swap 1 MON for USDC",
})

console.log(result.text)

Streaming Responses ​

typescript
import { streamText } from "ai"

const result = await streamText({
  model: openrouter("anthropic/claude-sonnet-4"),
  tools,
  maxSteps: 5,
  prompt: "What's my portfolio worth?",
})

for await (const chunk of result.textStream) {
  process.stdout.write(chunk)
}

Next.js API Route ​

typescript
// app/api/chat/route.ts
import { streamText } from "ai"
import { createOpenRouter } from "@openrouter/ai-sdk-provider"
import { createVercelAITools } from "@monad-agent-kit/ai-vercel"

export async function POST(req: Request) {
  const { messages } = await req.json()

  const result = await streamText({
    model: createOpenRouter({ apiKey: process.env.OPENROUTER_API_KEY })(
      "anthropic/claude-sonnet-4"
    ),
    tools: createVercelAITools(agent),
    maxSteps: 5,
    messages,
  })

  return result.toDataStreamResponse()
}

Tool Output ​

Each tool returns structured data that the AI can interpret:

typescript
// Example tool output
{
  success: true,
  data: {
    balance: "5.25",
    symbol: "MON",
    decimals: 18
  }
}

Supported Models ​

Works with any model that supports tool use:

  • Claude (via OpenRouter or Anthropic)
  • GPT-4 (via OpenRouter or OpenAI)
  • Gemini (via OpenRouter or Google)
  • Llama 3 (via OpenRouter)
