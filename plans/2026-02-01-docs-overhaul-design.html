Docs Overhaul Design ​

Date: 2026-02-01 Status: Approved

Goal ​

Make the documentation professional, compelling, and complete — serving both AI agent builders and Monad ecosystem developers equally.

1. Landing Page Overhaul ​

Replace the generic VitePress hero template with a purpose-built landing page:

  1. Hero — Tagline: "The native AI agent SDK for Monad". One-liner description. CTAs: "Get Started" + "View Examples"
  2. Why Monad Agent Kit — 3 cards comparing against generic EVM kits: native protocol integrations (Kuru, aPriori, MNS), production safety rails, 42 actions out of the box
  3. Code showcase — Real working example: agent executing a swap in ~10 lines. Copy-paste ready
  4. Ecosystem integrations — Badges for Vercel AI SDK, LangChain, MCP, Kuru, aPriori with links
  5. Action count — "42 on-chain actions across 5 plugins" with visual grid
  6. Quick install — bun add @monad-agent-kit/core on the homepage

File: docs/index.md
