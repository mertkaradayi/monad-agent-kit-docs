Tier 1 Features Design — Gas Estimation, Tx Simulation, NFT Support ​

3 features implemented in parallel via git worktrees.

Features ​

1. Gas Estimation ​

Action: estimateGas in plugin-tokens

Parameters:

ParamTypeRequiredDescription
tostringYesTarget address
valuestringNoMON amount to send (default "0")
datastringNoCalldata (hex string)
fromstringNoSender address (defaults to agent)

Returns:

typescript
{
  gasUnits: string        // "21000"
  gasPriceGwei: string    // "0.05"
  estimatedCostMON: string // "0.00000105"
}

Implementation:

  • eth_estimateGas for gas units
  • eth_gasPrice for current gas price
  • Multiply and format as MON

Files:

  • packages/plugin-tokens/src/actions/estimateGas.ts
  • packages/plugin-tokens/test/estimateGas.test.ts
  • docs/actions/estimate-gas.md
  • examples/mcp-claude-desktop/src/handlers.ts (add handler)
  • examples/mcp-claude-desktop/src/tools/gas.ts (new tool file)
  • examples/mcp-claude-desktop/src/tools/index.ts (register)
  • examples/mcp-claude-desktop/test/handlers.test.ts (add test)

2. Tx Simulation ​

Action: simulateTransaction in plugin-tokens

Parameters:

ParamTypeRequiredDescription
tostringYesTarget address
valuestringNoMON amount (default "0")
datastringNoCalldata (hex string)
fromstringNoSender address (defaults to agent)

Returns:

typescript
{
  success: boolean           // true if eth_call didn't revert
  returnData: string         // hex return data from eth_call
  error: string | null       // decoded revert reason if failed
  gasEstimate: string        // estimated gas units
  estimatedCostMON: string   // estimated cost in MON
}

Implementation:

  • eth_call to simulate execution, catch revert
  • eth_estimateGas + eth_gasPrice for cost (if call succeeds)
  • Decode revert reason from error data

Files:

  • packages/plugin-tokens/src/actions/simulateTransaction.ts
  • packages/plugin-tokens/test/simulateTransaction.test.ts
  • docs/actions/simulate-transaction.md
  • examples/mcp-claude-desktop/src/handlers.ts (add handler)
  • examples/mcp-claude-desktop/src/tools/gas.ts (add to same file)
  • examples/mcp-claude-desktop/test/handlers.test.ts (add test)

3. NFT Support (ERC-721) ​

New package: packages/plugin-nft/

Actions:

getNFTs ​

ParamTypeRequiredDescription
addressstringNoWallet to query (defaults to agent)
contractAddressstringYesERC-721 contract address

Returns: { nfts: Array<{ tokenId: string, contractAddress: string }> }

Implementation: Query Transfer events to/from address, compute owned set.

transferNFT ​

ParamTypeRequiredDescription
contractAddressstringYesERC-721 contract address
tokenIdstringYesToken ID to transfer
tostringYesRecipient address

Returns: { txHash: string }

Implementation: safeTransferFrom(from, to, tokenId)

getNFTMetadata ​

ParamTypeRequiredDescription
contractAddressstringYesERC-721 contract address
tokenIdstringYesToken ID

Returns: { name: string, symbol: string, tokenURI: string, metadata: object | null }

Implementation: tokenURI(tokenId) + fetch & parse JSON metadata if URI is HTTP/IPFS.

Worktree Setup ​

bash
# From main repo root
git worktree add ../monad-agent-kit-gas-estimation -b feat/gas-estimation
git worktree add ../monad-agent-kit-tx-simulation -b feat/tx-simulation
git worktree add ../monad-agent-kit-nft-support -b feat/nft-support

# Symlink .env.integration in each worktree
ln -s "$(pwd)/.env.integration" ../monad-agent-kit-gas-estimation/.env.integration
ln -s "$(pwd)/.env.integration" ../monad-agent-kit-tx-simulation/.env.integration
ln -s "$(pwd)/.env.integration" ../monad-agent-kit-nft-support/.env.integration

# Install deps in each
cd ../monad-agent-kit-gas-estimation && bun install
cd ../monad-agent-kit-tx-simulation && bun install
cd ../monad-agent-kit-nft-support && bun install

Per-Feature Checklist ​

Every feature follows this sequence:

  1. [ ] Implement action(s) in plugin
  2. [ ] Export from plugin index
  3. [ ] Write unit tests
  4. [ ] Run tests pass
  5. [ ] Add doc page(s) in docs/actions/
  6. [ ] Add to sidebar in docs/.vitepress/config.ts
  7. [ ] Update CLAUDE.md (available actions)
  8. [ ] Update README.md (action tables)
  9. [ ] Add MCP handler in examples/mcp-claude-desktop/src/handlers.ts
  10. [ ] Register MCP tool in examples/mcp-claude-desktop/src/tools/
  11. [ ] Update examples/mcp-claude-desktop/src/tools/index.ts
  12. [ ] Write MCP handler tests
  13. [ ] Run all tests pass
  14. [ ] Update docs/ROADMAP.md (check the box)
  15. [ ] Commit and push branch

Merge Order ​

  1. Gas estimation (smallest, no dependencies)
  2. Tx simulation (builds on similar patterns)
  3. NFT support (largest, independent package)

Each merges to main via PR. Rebase subsequent branches after each merge.

Shared Updates (after all 3 merge) ​

  • docs/ROADMAP.md — Check off all 3 items, update progress table
  • Final typecheck + lint across full repo
