getNFTs ​

Query ERC-721 NFTs owned by an address for a specific contract.

Parameters ​

ParameterTypeRequiredDescription
contractAddressstringYesERC-721 NFT contract address
addressstringNoWallet to query (defaults to agent wallet)

Returns ​

FieldTypeDescription
successbooleanWhether the query succeeded
data.nftsarrayList of owned NFTs with tokenId and contractAddress
data.ownerstringOwner address queried
data.countnumberNumber of NFTs owned

Examples ​

Get NFTs for Agent Wallet ​

typescript
const result = await agent.execute("getNFTs", {
  contractAddress: "0x1234...abcd",
})

if (result.success) {
  console.log(`Owns ${result.data.count} NFTs`)
  for (const nft of result.data.nfts) {
    console.log(`Token ID: ${nft.tokenId}`)
  }
}

Get NFTs for Another Address ​

typescript
const result = await agent.execute("getNFTs", {
  contractAddress: "0x1234...abcd",
  address: "0x742d35Cc6634C0532925a3b844Bc9e7595f1b3E0",
})

CodeDescription
NFT_QUERY_ERRORFailed to query Transfer events
