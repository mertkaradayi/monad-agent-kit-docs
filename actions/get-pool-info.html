On this page

getPoolInfo ​

Get pool/orderbook parameters for a Kuru DEX pool.

Parameters ​

ParameterTypeRequiredDescription
poolstringYesPool/orderbook contract address

Returns ​

FieldTypeDescription
successbooleanWhether the query succeeded
data.poolstringPool address
data.baseAssetstringBase token address
data.quoteAssetstringQuote token address
data.tickSizestringMinimum price increment
data.minSizestringMinimum order size
data.maxSizestringMaximum order size
data.takerFeeBpsstringTaker fee in basis points
data.makerFeeBpsstringMaker fee in basis points

Examples ​

Get Pool Info ​

typescript
const result = await agent.execute("getPoolInfo", {
  pool: "0xPoolAddress...",
})

if (result.success) {
  console.log(`Base Asset: ${result.data.baseAsset}`)
  console.log(`Quote Asset: ${result.data.quoteAsset}`)
  console.log(`Tick Size: ${result.data.tickSize}`)
  console.log(`Min Size: ${result.data.minSize}`)
  console.log(`Taker Fee: ${result.data.takerFeeBps} bps`)
}

Notes ​

  • Get pool info before adding liquidity to understand pool parameters
  • Tick size determines valid price increments
  • Min size determines minimum position size

Error Codes ​

CodeDescription
INVALID_POOLInvalid pool address
POOL_INFO_ERRORFailed to fetch pool info
