readContract ​

Call a read-only function on any smart contract.

When to use

Use this when you need to call any read-only function on a smart contract that isn't covered by specific actions.

Parameters ​

ParameterTypeRequiredDescription
addressstringYesContract address (0x...)
abiarrayYesABI array or single function ABI fragment
functionNamestringYesFunction name to call
argsarrayNoFunction arguments (default: [])

Returns ​

FieldTypeDescription
successbooleanWhether the call succeeded
data.resultunknownDecoded return value from the contract

Examples ​

Read Token Balance ​

typescript
const result = await agent.execute("readContract", {
  address: "0xf817257fed379853cDe0fa4F97AB987181B1E5Ea",
  abi: [{
    type: "function",
    name: "balanceOf",
    inputs: [{ name: "owner", type: "address" }],
    outputs: [{ name: "", type: "uint256" }],
    stateMutability: "view",
  }],
  functionName: "balanceOf",
  args: ["0x742d35Cc6634C0532925a3b844Bc9e7595f1b3E0"],
})

if (result.success) {
  console.log(`Raw balance: ${result.data.result}`)
}

Read Token Name ​

typescript
const result = await agent.execute("readContract", {
  address: "0xf817257fed379853cDe0fa4F97AB987181B1E5Ea",
  abi: [{
    type: "function",
    name: "name",
    inputs: [],
    outputs: [{ name: "", type: "string" }],
    stateMutability: "view",
  }],
  functionName: "name",
})

if (result.success) {
  console.log(`Token name: ${result.data.result}`)
}

Common Patterns ​

Agent prompts that trigger this action:

  • "Read the total supply of USDC"
  • "Check the owner of this contract"
  • "What's the name of the token at 0x...?"

Error Codes ​

CodeDescription
READ_CONTRACT_ERRORContract call failed (wrong ABI, invalid function, etc.)
VALIDATION_ERRORInvalid parameters

Notes ​

  • This is a built-in action registered automatically — no plugin needed
  • Returns raw decoded values (e.g., bigint for uint256)
  • Use this when the built-in actions don't cover your use case

Related Actions ​

  • writeContract - Execute state-changing contract calls
  • getBalance - Simpler way to check token balances
  • getTokenInfo - Simpler way to read token metadata
