getQuote ​

Get a quote for swapping tokens on Kuru DEX.

When to use

Use this action when you need to preview a swap's output amount and price impact before executing the swap.

Parameters ​

ParameterTypeRequiredDescription
tokenInstringYesInput token address (use 0x0...0 for native MON)
tokenOutstringYesOutput token address
amountInstringYesAmount of input token

Returns ​

FieldTypeDescription
successbooleanWhether the quote succeeded
data.outputstringExpected output amount
data.priceImpactnumberPrice impact percentage
data.routestringRouting path used

Examples ​

Get Swap Quote ​

typescript
const result = await agent.execute("getQuote", {
  tokenIn: "0x0000000000000000000000000000000000000000", // MON
  tokenOut: "0xf817257fed379853cDe0fa4F97AB987181B1E5Ea", // USDC
  amountIn: "10.0",
})

if (result.success) {
  console.log(`Input: 10 MON`)
  console.log(`Output: ${result.data.output} USDC`)
  console.log(`Price Impact: ${result.data.priceImpact}%`)
}

Notes ​

  • Always get a quote before executing a swap
  • High price impact (>1%) indicates low liquidity
  • Quote is an estimate; actual output may vary due to slippage

Common Patterns ​

Agent prompts that trigger this action:

  • "How much USDC will I get for 10 MON?"
  • "Get a quote for swapping MON to WETH"
  • "What's the exchange rate on Kuru?"

Error Codes ​

CodeDescription
INVALID_TOKENInvalid token address
NO_ROUTENo trading route found
INSUFFICIENT_LIQUIDITYNot enough liquidity

Related Actions ​
