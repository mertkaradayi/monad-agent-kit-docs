getBestQuote ​

Compare swap quotes from Kuru DEX and 0x aggregator to find the best price.

When to use

Use this action when you want the best price across all available DEX sources.

Parameters ​

ParameterTypeRequiredDescription
tokenInstringYesInput token address (use 0x0...0 for native MON)
tokenOutstringYesOutput token address
amountInstringYesAmount to swap (human-readable)
slippageBpsnumberNoSlippage for 0x quote in basis points (default: 50)
apiKeystringNoOptional 0x API key override

Returns ​

FieldTypeDescription
successbooleanWhether at least one quote was available
data.bestObjectBest quote: source ("kuru" or "0x"), amountOut, priceImpact
data.quotesObjectBoth quotes: kuru and zerox, each with amountOut, available, route, optional error
data.savingsPercentnumberPercentage savings vs the alternative (omitted if ≤0)

Examples ​

Compare Prices ​

typescript
const result = await agent.execute("getBestQuote", {
  tokenIn: "0x0000000000000000000000000000000000000000",
  tokenOut: "0xUSDC...",
  amountIn: "100.0",
})

if (result.success) {
  console.log(`Best: ${result.data.best.source} → ${result.data.best.amountOut} USDC`)
  if (result.data.savingsPercent) {
    console.log(`Saving ${result.data.savingsPercent}% vs alternative`)
  }
}

Notes ​

  • Fetches Kuru and 0x quotes in parallel
  • On testnet, only Kuru quotes are available (0x is mainnet only)
  • Kuru preferred when prices are equal
  • Read-only operation (no gas used)

Common Patterns ​

Agent prompts that trigger this action:

  • "Where do I get the best price for this swap?"
  • "Compare Kuru and 0x for 10 MON to USDC"
  • "Find the cheapest swap route"

Error Codes ​

CodeDescription
NO_QUOTESNeither source returned a valid quote
QUOTE_COMPARISON_ERRORComparison failed

Related Actions ​

  • getQuote - Kuru-only quote
  • getQuote0x - 0x-only quote
  • swap - Execute via Kuru
