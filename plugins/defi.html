DeFi Plugin ​

The DeFi Plugin provides actions for decentralized finance operations on Kuru DEX, 0x aggregator, and aPriori staking.

Installation ​

bash
bun add @monad-agent-kit/plugin-defi

Usage ​

typescript
import { defiPlugin } from "@monad-agent-kit/plugin-defi"

await agent.use(defiPlugin)

Quick Start ​

Here is a practical example showing how to get a quote and execute a swap:

typescript
import { MonadAgentKit } from "@monad-agent-kit/core"
import { defiPlugin } from "@monad-agent-kit/plugin-defi"

const agent = new MonadAgentKit({ privateKey: process.env.PRIVATE_KEY })
await agent.use(defiPlugin)

// Get quote for swapping 1 MON to USDC
const quote = await agent.execute("getQuote", {
  tokenIn: "0x0000000000000000000000000000000000000000", // MON
  tokenOut: "0xf817257fed379853cDe0fa4F97AB987181B1E5Ea", // USDC
  amountIn: "1.0",
})

console.log(`You will receive ~${quote.data.output} USDC`)
console.log(`Price impact: ${quote.data.priceImpact}%`)

// Execute the swap with 0.5% slippage tolerance
const result = await agent.execute("swap", {
  tokenIn: "0x0000000000000000000000000000000000000000",
  tokenOut: "0xf817257fed379853cDe0fa4F97AB987181B1E5Ea",
  amountIn: "1.0",
  slippage: 0.5,
})

console.log(`Swap executed: ${result.data.txHash}`)
console.log(`Received: ${result.data.amountOut} USDC`)

What You Can Build ​

Arbitrage Bot ​

Monitor price differences between Kuru DEX and 0x aggregator using getBestQuote, then execute profitable swaps automatically. Use multiSwap to batch multiple trades in a single transaction for gas efficiency.

DCA Agent ​

Implement dollar-cost averaging by scheduling periodic buys. Use getQuote to check current prices, swap to execute trades, and stake to automatically stake purchased MON for yield.

Liquidity Manager ​

Dynamically manage concentrated liquidity positions on Kuru. Monitor pool metrics with getPoolInfo and getLPPositions, rebalance ranges using removeLiquidity and addLiquidity, and use placeLimitOrder for limit-based position entry.

Examples ​

Swap Tokens ​

typescript
// Get a quote first
const quote = await agent.execute("getQuote", {
  tokenIn: "0x0000000000000000000000000000000000000000", // MON
  tokenOut: "0xf817257fed379853cDe0fa4F97AB987181B1E5Ea", // USDC
  amountIn: "1.0",
})

console.log(`Expected: ${quote.data.output} USDC`)
console.log(`Price Impact: ${quote.data.priceImpact}%`)

// Execute swap
const swap = await agent.execute("swap", {
  tokenIn: "0x0000000000000000000000000000000000000000",
  tokenOut: "0xf817257fed379853cDe0fa4F97AB987181B1E5Ea",
  amountIn: "1.0",
  slippage: 0.5, // 0.5%
})

Wrap/Unwrap MON ​

typescript
// Wrap MON to WMON (needed for some DeFi protocols)
await agent.execute("wrapMON", { amount: "10.0" })

// Unwrap WMON back to MON
await agent.execute("unwrapWMON", { amount: "10.0" })

Provide Liquidity ​

typescript
// Get pool info
const pool = await agent.execute("getPoolInfo", {
  pool: "0xPoolAddress...",
})

// Add liquidity with price range
const lp = await agent.execute("addLiquidity", {
  pool: "0xPoolAddress...",
  quoteLiquidity: "100", // 100 USDC
  startPrice: "0.9",
  endPrice: "1.1",
  strategy: "spot", // even distribution
})

// Remove liquidity
await agent.execute("removeLiquidity", {
  pool: "0xPoolAddress...",
  orderIds: [1, 2, 3],
})

Stake MON ​

typescript
const stake = await agent.execute("stake", { amount: "10.0" })
console.log(`Received ${stake.data.sharesReceived} aprMON`)

// Later: unstake
const unstake = await agent.execute("requestUnstake", { shares: "5.0" })
console.log(`Request ID: ${unstake.data.requestId} — claim after 12-18h`)

// After waiting period:
const claim = await agent.execute("claimUnstake", { requestId: 42 })
console.log(`Claimed ${claim.data.monClaimed} MON`)

Compare and Swap ​

typescript
const best = await agent.execute("getBestQuote", {
  tokenIn: "0x0000000000000000000000000000000000000000",
  tokenOut: "0xUSDC...",
  amountIn: "100.0",
})
console.log(`Best source: ${best.data.best.source} → ${best.data.best.amountOut} USDC`)

Use 0x0000000000000000000000000000000000000000 for native MON in swaps.
