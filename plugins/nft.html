NFT Plugin ​

The NFT Plugin provides actions for ERC-721 NFT operations.

Installation ​

bash
bun add @monad-agent-kit/plugin-nft

Usage ​

typescript
import { nftPlugin } from "@monad-agent-kit/plugin-nft"

await agent.use(nftPlugin)

Quick Start ​

Here's a complete workflow showing how to query NFTs and transfer one:

typescript
import { MonadAgentKit } from "@monad-agent-kit/core"
import { nftPlugin } from "@monad-agent-kit/plugin-nft"

const agent = new MonadAgentKit({ privateKey: process.env.PRIVATE_KEY })
await agent.use(nftPlugin)

// 1. Check which NFTs you own
const nfts = await agent.execute("getNFTs", {
  contractAddress: "0x1234...abcd",
})

console.log(`Found ${nfts.data.count} NFTs`)
if (nfts.data.count > 0) {
  const firstNFT = nfts.data.tokenIds[0]

  // 2. Get metadata for the first NFT
  const metadata = await agent.execute("getNFTMetadata", {
    contractAddress: "0x1234...abcd",
    tokenId: firstNFT,
  })

  console.log(`NFT #${firstNFT}: ${metadata.data.metadata?.name}`)

  // 3. Transfer it to another address
  const transfer = await agent.execute("transferNFT", {
    contractAddress: "0x1234...abcd",
    tokenId: firstNFT,
    to: "0x742d35Cc6634C0532925a3b844Bc9e7595f1b3E0",
  })

  console.log(`Transferred! TX: ${transfer.data.txHash}`)
}

What You Can Build ​

NFT Gallery Bot: Build an AI agent that queries a user's NFT holdings across multiple collections, fetches metadata for each, and generates a formatted gallery report with images, names, and rarity info.

Airdrop Checker: Create an agent that monitors specific NFT contracts for new mints or transfers to your wallet, retrieves metadata automatically, and notifies you when you receive an airdrop.

Collection Tracker: Build a bot that tracks NFT collections by periodically querying owner balances, detecting transfers, and maintaining a live leaderboard of top holders.

Actions ​

ActionDescription
getNFTsQuery NFTs owned by an address
transferNFTTransfer an NFT to another address
getNFTMetadataGet metadata for a specific NFT

Examples ​

List Owned NFTs ​

typescript
const result = await agent.execute("getNFTs", {
  contractAddress: "0x1234...abcd",
})
console.log(`Owns ${result.data.count} NFTs`)

Transfer an NFT ​

typescript
const result = await agent.execute("transferNFT", {
  contractAddress: "0x1234...abcd",
  tokenId: "42",
  to: "0x742d35Cc6634C0532925a3b844Bc9e7595f1b3E0",
})
console.log(`TX: ${result.data.txHash}`)

Get NFT Metadata ​

typescript
const result = await agent.execute("getNFTMetadata", {
  contractAddress: "0x1234...abcd",
  tokenId: "42",
})

if (result.data.metadata) {
  console.log(`Name: ${result.data.metadata.name}`)
  console.log(`Image: ${result.data.metadata.image}`)
}
