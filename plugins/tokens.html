Tokens Plugin ​

The Tokens Plugin provides actions for token information, pricing, portfolio tracking, and discovery.

Installation ​

bash
bun add @monad-agent-kit/plugin-tokens

Usage ​

typescript
import { tokensPlugin } from "@monad-agent-kit/plugin-tokens"

await agent.use(tokensPlugin)

Quick Start ​

Here's a practical workflow showing token discovery, price checking, and portfolio analysis:

typescript
import { MonadAgentKit } from "@monad-agent-kit/core"
import { tokensPlugin } from "@monad-agent-kit/plugin-tokens"

const agent = new MonadAgentKit({ privateKey: process.env.PRIVATE_KEY })
await agent.use(tokensPlugin)

// 1. Get token info
const usdc = await agent.execute("getTokenInfo", {
  token: "0xf817257fed379853cDe0fa4F97AB987181B1E5Ea",
})
console.log(`Found: ${usdc.data.name} (${usdc.data.symbol})`)

// 2. Check current price
const price = await agent.execute("getTokenPrice", {
  token: "0x0000000000000000000000000000000000000000", // MON
})
console.log(`MON price: $${price.data.price}`)

// 3. View full portfolio with USD values
const portfolio = await agent.execute("getPortfolio", {
  includePrices: true,
})
console.log(`Total portfolio value: $${portfolio.data.totalValueUsd}`)
console.log(`Holdings: ${portfolio.data.tokens.length} tokens`)

Actions ​

ActionDescription
getTokenInfoGet token metadata (name, symbol, decimals, supply)
getTokenPriceGet real-time price via DEX quotes
getPortfolioGet full portfolio with USD values (Multicall3 batched, 48 known tokens)
getTransactionHistoryGet wallet transaction history
getFirstActivityFind wallet's first on-chain activity
estimateGasEstimate gas cost before executing a transaction
simulateTransactionDry-run a transaction to preview success/failure and gas cost
getActionHistoryGet agent's action execution log
getActionStatsGet aggregated action statistics

Examples ​

Get Token Information ​

typescript
const info = await agent.execute("getTokenInfo", {
  token: "0xf817257fed379853cDe0fa4F97AB987181B1E5Ea", // USDC
})
console.log(`${info.data.name} (${info.data.symbol})`)
console.log(`Decimals: ${info.data.decimals}`)
console.log(`Total Supply: ${info.data.totalSupply}`)

Get Token Price ​

typescript
// Get MON price in USD
const price = await agent.execute("getTokenPrice", {
  token: "0x0000000000000000000000000000000000000000", // native MON
})
console.log(`MON = $${price.data.price}`)

Get Full Portfolio ​

Portfolio checks 48 known mainnet tokens in a single batched RPC call via Multicall3. On testnet, set ALCHEMY_API_KEY for complete discovery of all tokens including airdrops (Alchemy does not support Monad mainnet yet).

typescript
const portfolio = await agent.execute("getPortfolio", {
  includePrices: true,
})

console.log(`Total Value: $${portfolio.data.totalValueUsd}`)
for (const token of portfolio.data.tokens) {
  console.log(`${token.symbol}: ${token.balance} ($${token.valueUsd})`)
}

Get Transaction History ​

typescript
const history = await agent.execute("getTransactionHistory", {
  limit: 10,
  type: "all",
})

for (const tx of history.data.transactions) {
  console.log(`${tx.type}: ${tx.value} ${tx.token?.symbol || "MON"}`)
}

What You Can Build ​

Portfolio Dashboard ​

Build a real-time wallet analytics dashboard that tracks token holdings, USD values, transaction history, and first activity timestamps. Use getPortfolio for batched balance queries (48 tokens in one RPC call via Multicall3), getTokenPrice for live pricing, and getTransactionHistory to show recent activity.

Price Alert Bot ​

Create an automated monitoring system that tracks token prices and triggers alerts when thresholds are crossed. Use getTokenPrice for current quotes, estimateGas to preview transaction costs before swapping, and simulateTransaction to validate trades before execution.

Wallet Analytics Tool ​

Analyze wallet behavior and on-chain patterns using getFirstActivity to find when addresses became active, getTransactionHistory to categorize transaction types, and getActionHistory / getActionStats to track agent execution patterns and success rates over time.
